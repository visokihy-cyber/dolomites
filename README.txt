ДОЛОМИТЫ · ОСЕНЬ 2026

1. Распакуйте архив и откройте dolomites-autumn-2026.html в современном браузере.
2. По умолчанию выбрана онлайн-карта OpenTopoMap. Без сети выберите «Офлайн · Доломиты». Карта района, линии и высотные профили встроены в HTML. Этот HTML можно переносить отдельно от остальных файлов.
3. Онлайн-основы и внешние ссылки требуют интернета. Офлайн-карта охватывает район всех девяти маршрутов, а не весь мир; она не содержит спутниковых снимков и горизонталей.
4. В папке route-tracks — девять маршрутов 01–09. Для каждого есть KML и GPX с пешими линиями и ключевыми точками. Файлы 01-route-short — кольцо Tre Cime без Cadini, 02-route-short — только озеро Braies. В атласе кнопка скачивает текущий выбранный вариант. Автомобильные переезды и канатки в пешие файлы не включены.
5. На телефоне откройте KML/GPX через «Открыть в Organic Maps». Заранее скачайте карты регионов в самом приложении. Файл трека не включает карту. Скачивание из HTML тоже работает без сети, если браузер поддерживает сохранение локальных файлов.

Это планировочные линии по OSM, не запись GPS и не проверенные на местности навигационные треки. Высоты не экспортированы: DEM отражает поверхность и неточна у скал/тоннелей. Отдельные пешие участки не соединены прямыми линиями через горы.
