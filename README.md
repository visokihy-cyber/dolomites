# Доломиты · топ-локации на выходной

Планировщик одного-двух осенних дней: девять маршрутов, короткие варианты Tre Cime и Braies, фотографии, подбор по нагрузке, переезды и подготовка к прогулке.

Открыть сайт: https://visokihy-cyber.github.io/dolomites/

Сначала выберите треки и добавьте их в «Мой план». Район для ночёвки предлагается после выбора маршрутов. План сохраняется на устройстве; ссылку можно отправить попутчикам. Прогноз находится внутри раздела «Осенью и перед выходом».

Веб-версия загружает фото и географию отдельно. Для работы без сети скачайте `dolomites-offline-and-tracks.zip`, распакуйте и откройте `dolomites-autumn-2026.html`. В полном файле встроены карта района, фотографии, линии и профили. По умолчанию открывается OpenTopoMap; без сети переключитесь на «Офлайн · Доломиты». Внешние ссылки, свежий прогноз и онлайн-карты требуют сети.

KML и GPX содержат выбранный пеший маршрут с ключевыми точками. Это планировочные линии по OpenStreetMap, без проверки прохождением на местности. Высоты EU-DEM приблизительны и не экспортируются. Расписания и ограничения имеют даты проверки; опубликованный график не подтверждает фактическое открытие объекта в момент поездки.
