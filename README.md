# Доломиты · Осень 2026

Интерактивный атлас: 9 дневных маршрутов, встроенная офлайн-карта района, высотные профили, тарифы подъёмников и скачивание KML/GPX.

Открыть сайт: https://visokihy-cyber.github.io/dolomites/

Для работы без сети скачайте index.html и откройте в современном браузере. Карта района, рекомендации и треки встроены в файл. Онлайн-подложки и внешние ссылки требуют интернета.

Линии восстановлены по OpenStreetMap для планирования, это не проверенные навигационные GPX. Высоты EU-DEM приблизительны; фактические закрытия не обновляются.

Данные © OpenStreetMap contributors, ODbL: https://www.openstreetmap.org/copyright

Офлайн-данные OSM от 09.09.2026 упрощены и встроены в блок atlas-data. Высоты EU-DEM v1.1 / Copernicus через Open Topo Data интерполированы вдоль треков; produced with funding by the European Union. Поддержка атласа со стороны ЕС не подразумевается.
